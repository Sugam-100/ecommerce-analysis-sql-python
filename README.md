📦 E-commerce Data Analysis with SQL + Python

An end-to-end analytical project using MySQL and Python to explore and visualize customer behavior, product sales, regional engagement, and growth trends in an e-commerce platform.

🎯 Objective

To analyze e-commerce data by integrating SQL queries with Python-based visualization in Jupyter Notebook. The goal is to generate actionable business insights from customer, order, payment, and product data.

🔧 Tech Stack
📚 Python (Pandas, NumPy) – Data manipulation and calculations
📊 Matplotlib & Seaborn – Visualizations
🛢 MySQL – Querying relational datasets
📝 Jupyter Notebook – Interactive data exploration
📁 CSV Files – Used for database population and local analysis

📂 Data Source

The dataset consists of multiple CSV files (customers, orders, payments, products, order_items, sellers, geolocation) representing a full-scale e-commerce platform. Data was inserted into MySQL tables and analyzed using SQL + Python.
Dataset used from: Brazilian E-commerce Public Dataset

🔍 Key Insights & Features

📌 State-wise customer distribution
📆 Monthly order trends in 2018
💳 Percentage of installment payments
🎯 Top-selling product categories
📈 Cumulative & Year-on-Year sales growth
🔁 Repeat customer rate within 6 months
💼 Revenue generated by top sellers & customers
📊 Correlation between product count and price

📸 Visuals

Bar plots: Orders per month, state-wise customers, seller revenue
Line plots: Cumulative sales trends
Seaborn: Heatmaps, bar-labeling insights
SQL Window Functions: Moving averages, rank, YoY % growth

📌 Business Value

✅ Helps understand sales patterns, revenue breakdown, and customer engagement
✅ Enables strategic marketing & stocking based on product demand
✅ Supports data-driven growth forecasting and seller performance evaluation
